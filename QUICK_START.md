# ⚡ Quick Start Guide

## Fastest Way to Run (3 Steps)

### Step 1: Install Dependencies
```bash
pip install -r requirements.txt
```

### Step 2: Run the App
```bash
python app.py
```

### Step 3: Open Browser
Go to: **http://localhost:5000**

That's it! 🎉

---

## What You'll See

- **Live Dashboard** updating every 5 seconds
- **Real-time Statistics** for all zones
- **AI Recommendations** panel
- **Interactive Charts** showing footfall and energy
- **Traffic Heatmap** with color-coded zones

---

## Troubleshooting

**Problem**: `pip` not found
**Solution**: Use `pip3` instead, or `python -m pip install -r requirements.txt`

**Problem**: Port 5000 already in use
**Solution**: The app will tell you. Just use a different port or close the other app.

**Problem**: Charts not showing
**Solution**: Make sure you have internet (Chart.js loads from CDN)
